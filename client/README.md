# AI Assistant

A full-stack AI assistant web application with authentication, memory, file uploads, voice input, and AI-powered conversations.

---

## Features

- AI chat interface
- User authentication
- Persistent chat memory
- File uploads
- Voice input support
- Markdown and code rendering
- Streaming AI responses
- Responsive modern UI

---

## Tech Stack

### Frontend
- React
- Axios
- Framer Motion

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

### AI Integration
- OpenAI API / Gemini API

---

```bash
client/
server/
```

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/ai-assistant.git
cd ai-assistant
```

---

## Frontend Setup

```bash
cd client
npm install
npm start
```

---

## Backend Setup

```bash
cd server
npm install
npm start
```

---

## Environment Variables

Create a `.env` file inside `server/`

```env
OPENAI_API_KEY=your_key
GEMINI_API_KEY=your_key
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
```
